# Лабораторна робота
## "Кластеризація та класифікація інформації"
## Ходаков Максим Олегович ШІ-2

Тестування, дослідження та аналіз алгоритмів кластеризації K-Means, GMM (EM), DBSCAN
та агломеративної кластеризації Уорда на 16 наборах числових даних.

### Структура

| Шлях | Зміст |
|---|---|
| `src/datasets.py` | генератори наборів (кола/кулі, еліпси, квадрати, прямокутники, паралелепіпеди, літери, кільця, суміш; датчики PCG64/MT19937/Philox/SFC64) та реальні набори Iris і Wine |
| `src/algorithms.py` | запуск алгоритмів, вибір параметрів DBSCAN, вимірювання часу та пам'яті |
| `src/stability.py` | δ-зсуви точок і наборів точок, зіставлення міток (угорський алгоритм), залежність від ініціалізації |
| `src/visualize.py` | візуалізація вихідних даних, проміжних і остаточних результатів |
| `src/run_experiments.py` | виконує всі експерименти |
| `results/figures`, `results/tables` | рисунки та CSV-таблиці, на яких побудовано звіт |
| `report/` | генератор звіту `.docx` (Node.js, бібліотека `docx`) |
| `Звіт_Лабораторна_робота_ККІ.docx` | звіт |

### Відтворення результатів

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m src.run_experiments          # ~1 хв, перезаписує results/
```

### Перегенерування звіту

Потрібні Node.js, LibreOffice (`soffice`) та `pdftotext` (poppler) — вони використовуються,
щоб визначити номери сторінок для змісту.

```bash
cd report && npm install
node build.js ../Звіт_Лабораторна_робота_ККІ.docx
```
